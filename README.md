# 🚀 FinShield AI - Fraud Detection System

## 🔍 Overview
FinShield AI is an intelligent fraud detection system that uses Machine Learning and AI to detect suspicious financial transactions and provide human-readable explanations.

---

## 🧠 Key Features

- Fraud detection using Machine Learning (Random Forest)
- Risk scoring based on transaction data
- Rule-based fraud indicators (amount, location, merchant)
- AI-generated explanations using Gemini API
- FastAPI backend for real-time predictions
- Streamlit dashboard for user interaction

---

## 🛠️ Tech Stack

- Python
- FastAPI
- Scikit-learn
- Streamlit
- Pandas & NumPy
- Gemini AI

---

## 💡 How It Works

1. User enters transaction details  
2. ML model predicts fraud probability  
3. Rule-based logic evaluates risk  
4. Gemini AI explains the result  
5. Output displayed on dashboard  

---

## 🎯 Use Case

- Banking fraud detection  
- Payment security systems  
- Financial risk analysis
